# EXERCISES BY ORDER IN C 

## Exercise 1 : **Caisse**
* **Description:** A simple cash register program that continuously sums up item prices until the user enters `0`.

## Exercise 2 : **Controle**
* **Description:** A security access control program that repeatedly prompts for a PIN code until the correct one (`1234`) is entered, then displays the total number of failed attempts.

## Exercise 3 : **Verif_code**
* **Description:** A PIN verification system that limits the user to a maximum of 3 attempts, granting access if correct or blocking the user if all attempts fail.

## Exercise 4 : **Retrait**
* **Description:** A cash withdrawal simulation that authenticates the user with a 3-attempt limit, checks the account balance, and processes the withdrawal if funds are sufficient.

## Exercise 5 : **Atm**
* **Description:** A complete ATM simulation featuring secure PIN authentication (max 3 attempts) and an interactive menu to check balance, withdraw cash, or deposit funds.
